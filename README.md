# ミリア・レフス 新規アニメーション素材セット

## フレーム仕様
- 画像は **RGBA透明PNG**。背景・説明文字・罫線・フレーム番号は含まれません。
- 全フレーム **384×384px**。描画基準は x=190, 足元 y=339。
- ①待機16、②移動16、③ジャンプ16、④縦斬り20、⑤横斬り20、⑥逆袈裟斬り20 = **108コマ**。
- 6行20列の統合アトラスも収録（最初の3行は各16コマで、残り4列は透明）。
- 攻撃エフェクトは3種類×20フレームを **別のPNG** に保存。近接斬撃であり、飛び道具ではありません。
- 元の納刀・抜刀日本刀素材は参考用としてそのまま同梱しています。

## 推奨フレーム速度
- 待機8FPS（1ループ1回の瞬き）
- 移動12FPS
- ジャンプ12FPS（上昇・降下の移動量はゲーム側の物理演算で制御）
- 斬撃18FPS、コンボは1→2→3の順番で連結可能

## Canvas描画例
```js
const W = 384, H = 384;
ctx.imageSmoothingEnabled = false;
ctx.drawImage(sprite, frame * W, 0, W, H, drawX, drawY, drawW, drawH);
// 攻撃時だけ同じ座標と倍率でFXを描く
ctx.drawImage(effect, frame * W, 0, W, H, drawX, drawY, drawW, drawH);
```
左向きの場合はキャラとエフェクト両方を反転してください。

## 品質上の注意
描画原画は生成画像を元に一コマごとに切り出し・配置しており、近いポーズを再利用した箇所があります。特に刀の左右・鞘の保持位置や連続した関節運動は、実装前に個別フレームを目視確認・必要に応じてドット単位の修正をしてください。完全に手打ちで描かれた108コマの商用アニメーションを保証するものではありません。
